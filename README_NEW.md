## Overview

CET-KG is a research project investigating how temporal knowledge graph
forecasting can be made more trustworthy by combining:

1. **Temporal KG Forecasting** — Predict future events from historical patterns
2. **Conformal Calibration** — Construct prediction sets with coverage guarantees
3. **Graph-Grounded Explanation** — Identify historical evidence supporting predictions
4. **Noise Robustness** — Evaluate degradation under data corruption

### Pipeline Architecture

```
Synthetic Geopolitical Events (3,953 events, 15 countries, 10 relations)
        ↓
Temporal Knowledge Graph (NetworkX MultiDiGraph)
        ↓
Feature Extraction (26 temporal + pair features)
        ↓
Multi-class Relation Forecasting (RandomForest)
        ↓
Split-Conformal Calibration (prediction sets, ~90% coverage)
        ↓
Graph-Grounded Evidence Explanation (heuristic relevance)
        ↓
Noise Robustness Evaluation (intensity + label noise)
```

## Quick Start (Mac M2)

### 1. Prerequisites

- Python 3.10+ (tested with 3.13)
- pip

### 2. Install Dependencies

```bash
cd "CET-KG (PBL PROJECT)"
pip3 install -r requirements.txt
```

### 3. Run the Pipeline

```bash
# Quick run (~8 seconds, skip noise experiments):
python3 code/run_pipeline.py --seed 42 --target-coverage 0.90 --skip-noise

# Full run (~90 seconds, with noise experiments):
python3 code/run_pipeline.py --seed 42 --target-coverage 0.90
```

### 4. Launch the Dashboard

```bash
streamlit run code/app.py
```

Open `http://localhost:8501` in your browser.

### 5. Run Tests

```bash
python3 code/tests.py
```

## Components

### Data Layer (`data_layer.py`)
- Generates synthetic geopolitical TKG events (ICEWS/GDELT-inspired)
- 15 countries, 10 relation types, 365 days
- Configurable pair-relation affinities for non-uniform data
- Chronological splitting: train (0–249), calibration (250–299), test (300–364)

### Temporal Graph (`temporal_graph.py`)
- NetworkX MultiDiGraph with temporal edge attributes
- Temporal subgraph extraction (entity + time window)
- Feature computation: degree, relation entropy, intensity, recency

### Forecasting (`forecasting.py`)
- Task: multi-class relation prediction for (head, tail) at time T
- 26 features: entity-level + pair-level temporal statistics
- RandomForest classifier (CPU-friendly, no GPU)
- Strict temporal integrity: no future data leakage

### Conformal Calibration (`conformal.py`)
- Split-conformal prediction sets
- Non-conformity score: 1 − P(true class)
- Finite-sample-corrected quantile
- Coverage by time bucket analysis
- **Caveat:** exchangeability violated under temporal dependence

### Explainability (`explainability.py`)
- Evidence-based prototype (not SHAP/gradient attribution)
- Heuristic relevance: entity overlap + relation match + recency
- NetworkX subgraph visualization
- Human-readable explanation text

### Noise Robustness (`noise_eval.py`)
- Historical noise: Gaussian perturbation of event intensity
- Label noise: random relation label flipping
- Configurable noise levels
- Comparison of accuracy, coverage, and set size
